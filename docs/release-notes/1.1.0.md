# Clawdio 1.1.0

Windows portable release of Clawdio, a local music player.

## New: snap grid layout

- The window is a grid of 12 columns and 12 rows. The grid fills the window, so every widget scales with it.
- Drag a widget by its header to move it. Drag its edge or corner to resize it. Widgets snap to whole cells, and a preview shows the target cells.
- A drop pushes other widgets down. Nothing goes past the last row: widgets shrink to make room, else the drop is refused and the preview shows red.
- Artist, Album, Songs, Tree and Search are separate widgets. Transport controls is a widget too.
- With a widget header focused, Alt+arrow keys move the widget and Alt+Shift+arrow keys resize it. The menu also has "Arrange" for the active widget.
- Three presets: Default, Tree and Columns. Reset layout (Ctrl+Shift+L) applies Default.
- Tabbed and floating widget groups, the Library mode switch and the transport bar position setting are removed.

## Your saved layout

A layout from an earlier version is not converted. At the first start, the app keeps a copy as `layout.json.bak` in the `data` folder and opens the Default preset. Your queue, playlists, settings and song column choices stay.

## Windows portable

Download `Clawdio-1.1.0-windows-portable.zip` and extract it to a writable folder.
Start `Clawdio.exe`. Keep the `portable` marker beside the executable. Settings,
state, cache and logs go in the `data` folder beside it.

The portable app needs the Microsoft Edge WebView2 Runtime. If it is missing,
the app shows a download link.

`SHA256SUMS-windows.txt` contains the SHA-256 checksum of the zip. This release
ships the Windows portable zip only.
